## BUG-01. Проверка имени учитывает крайние пробелы

- Требование и влияние на пользователя: R1. Можно создать заявку с именем короче двух символов после удаления крайних пробелов.
- Условия: Live Server, обычный режим, после сброса стенда три исходные заявки.
- Данные и шаги:
  1. Ввести имя ` А ` с пробелами по краям.
  2. Выбрать «HTML и CSS».
  3. Оставить комментарий пустым.
  4. Один раз нажать «Отправить заявку».
- Ожидалось: сообщение об ошибке длины имени, новая заявка не создаётся.
- Получилось: появилась четвёртая заявка с именем `А`. Свидетельство — наблюдение в списке заявок.
- Исправление: `src/app.js`, добавлен `.trim()` при чтении имени до вызова `validate()`. Коммит: `fix: проверять длину имени без крайних пробелов`.
- Повторная проверка: с именем ` А ` появляется ошибка, остаются три заявки.
- Соседняя проверка: имя `Ан` с выбранным направлением и пустым комментарием создаёт одну заявку. Имя ` Ан ` сохраняется как `Ан`. Без выбранного направления новая заявка не создаётся.
